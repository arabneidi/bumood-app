## 📝 **How to Set Your Preferences:**

### **Step 1: Go to Profile Page**
- Click **"Profile"** button in navigation (cyan button)

### **Step 2: Fill Basic Info**
- Name, Gender, Age, Height, Weight

### **Step 3: Select Your Interests**
- Click on interest buttons (gym, sports, poetry, etc.)
- Select ALL that apply (multiple selection)
- Selected interests turn purple

### **Step 4: Choose Quote Style**
- Select from dropdown (Motivational, Poetic, Sporty, etc.)

### **Step 5: (Optional) Add Favorite Authors**
- Type names separated by commas
- Example: "Maya Angelou, Kobe Bryant, Rumi"

### **Step 6: Save Profile**
- Click "Save Profile" button
- See confirmation message
