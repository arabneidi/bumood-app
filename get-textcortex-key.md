# 🚀 Get TextCortex API Key (Free & Works in Canada)

## **Quick Steps:**

1. **Go to**: https://textcortex.com/
2. **Click**: "Sign Up" (top right)
3. **Create account** with email
4. **Go to**: https://textcortex.com/api
5. **Copy your API key**
6. **Add to `.env` file**:
   ```bash
   TEXTCORTEX_API_KEY="your_actual_key_here"
   ```
